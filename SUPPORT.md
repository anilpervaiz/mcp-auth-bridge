# Support

Start with the [documentation](docs/index.md) and [troubleshooting guide](docs/troubleshooting.md).

Use [GitHub issues](https://github.com/anilpervaiz/mcp-auth-bridge/issues) for
installation problems, reproducible bugs, and feature proposals. Include the
package version, Python version, operating system, MCP client/version, expected
behavior, and a minimal example with synthetic values. Include a fixed error code
or safe report instead of raw HTTP or browser output.

Do not post tokens, passwords, authorization codes, identities, callback URLs with
queries, private endpoint details, or unredacted logs. Suspected vulnerabilities
belong in the [private reporting channel](SECURITY.md).

This is a free, maintainer-led alpha with best-effort support. It has no uptime or
response-time guarantee. Supported and unverified combinations are identified in
the [compatibility record](docs/compatibility.md); protocol compatibility is exact,
not an assumption based on a client supporting MCP generally.

The first release supports self-hosting the Python boundary. Hosted onboarding,
multi-tenant routing, legacy MCP transports, and operation of a user's deployment
are outside the alpha support commitment.
